# 2. Jenkins Setup bằng Docker

## Jenkins service

```yaml
jenkins:
  build:
    context: .
    dockerfile: Dockerfile.jenkins
  user: root
  ports:
    - "8082:8080"
    - "50000:50000"
  volumes:
    - jenkins_home:/var/jenkins_home
    - /var/run/docker.sock:/var/run/docker.sock
```

---

## Lấy password Jenkins

```bash
docker exec -it <container-id> cat /var/jenkins_home/secrets/initialAdminPassword
```

---

## Jenkins cần Docker socket

```yaml
- /var/run/docker.sock:/var/run/docker.sock
```

=> để Jenkins gọi Docker trên máy host.

# 5. Docker Build + Deploy

## Build image

```groovy
sh 'docker build -t $IMAGE_NAME ./myapp'
```

---

## Deploy container

```groovy
sh '''
docker stop my-app-container || true
docker rm my-app-container || true

docker run -d \
  -p 8089:8089 \
  --name my-app-container \
  $IMAGE_NAME
'''
```

# 7. Spring Boot Actuator + Prometheus

## Dependencies

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>

<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-registry-prometheus</artifactId>
</dependency>
```

---

## application.yml

```yaml
management:
  endpoints:
    web:
      exposure:
        include: "*"

  endpoint:
    prometheus:
      access: unrestricted
```

---

## Endpoint

```txt
http://localhost:8089/actuator/prometheus
```

---

# 8. Prometheus Setup

## docker-compose

```yaml
prometheus:
  image: prom/prometheus
  ports:
    - "9090:9090"
  volumes:
    - ./prometheus.yml:/etc/prometheus/prometheus.yml
```

---

## prometheus.yml

```yaml
global:
  scrape_interval: 5s

scrape_configs:
  - job_name: 'spring-app'

    metrics_path: '/actuator/prometheus'

    static_configs:
      - targets: ['app:8089']
```

---

## Verify

```txt
http://localhost:9090
```

Query:

```promql
up
```

Expected:

```txt
up{job="spring-app",instance="app:8089"} 1
```

# 10. Grafana Dashboard Issues

## JVM metrics có data nhưng dashboard N/A

Nguyên nhân:

Dashboard cũ filter theo:

```txt
application=
```

nhưng Spring Boot Micrometer expose:

```txt
job=
instance=
```

---

## Fix variables

### application

```txt
label_values(up, job)
```

---

### instance

```txt
label_values(up, instance)
```
